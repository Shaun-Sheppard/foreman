Agent Launcher · visual system note · v1 · 9 Oct 2026 Neutral base, five status colours, one type family Everything is grey except status. Colour always travels with a shape and a word, so nothing depends on colour alone. Primary buttons are high-contrast neutral rather than coloured, so the only coloured things on screen are the ones that changed state.
