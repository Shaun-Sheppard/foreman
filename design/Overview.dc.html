Title bar holds the top bar. One 40px row saves vertical space for the list; generic window glyphs avoid copying macOS or Windows. Ready to merge counts as "Needs you". It's blocked on his click, so it sits with Needs input, PR failed and Stuck. Primary buttons are neutral, not coloured. Colour is kept for status, so it never competes with the things that need him. Attention = filled shape + tint + bold + reason. Quiet items use hollow icons, so a needs-attention card reads in greyscale. Geist + Geist Mono. One family in two cuts keeps IDs, branches and logs aligned with the UI text and stays legible at 11–13px. Action first in the detail pane. Start / Fix it / Merge / Approve always sit above the scroll, so the core action is one click after selecting.
